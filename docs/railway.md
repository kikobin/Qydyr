# Деплой на Railway

Один сервис: API, Mini App и Telegram-бот в одном процессе. База — Supabase (PostGIS). Railway собирает `Dockerfile`, настройки сервиса лежат в `railway.json`: проверка здоровья `/health`, перезапуск при падении.

## 1. Сервис

1. Railway → **New Project** → **Deploy from GitHub repo** → `kikobin/Qydyr`. В настройках сервиса (**Settings → Source**) выберите ветку, с которой деплоить.
2. **Settings → Networking → Generate Domain**. Railway даст адрес вида `https://qydyr-production.up.railway.app`. `QYDYR_PUBLIC_URL` можно не задавать: приложение возьмёт этот домен само (`RAILWAY_PUBLIC_DOMAIN`). Свой домен — тогда задайте `QYDYR_PUBLIC_URL`.
3. **Variables → Raw Editor** — вставьте переменные (таблица ниже) → **Deploy**.
4. Реплика должна быть одна, засыпание сервиса (**Serverless**) — выключено: бот работает через polling, второй экземпляр или спящий сервис ломают его.

## 2. Переменные

| Переменная | Обязательна | Что это |
|---|---|---|
| `DATABASE_URL` | да | Supabase → Project Settings → Database → Connection string → **Session pooler** (работает по IPv4) |
| `TELEGRAM_BOT_TOKEN` | для бота | токен от @BotFather. Без него работают API и Mini App |
| `ANTHROPIC_API_KEY` | нет, но нужен для демо | понимание запросов, «почему» от Claude, перевод, фото, разбор афиш |
| `QYDYR_DGIS_KEY` | нет | 2ГИС: адрес вместо геолокации («я на Кенесары 40») и еженедельное обновление. Собранные данные 2ГИС загружаются без ключа |
| `GROQ_API_KEY` | нет, но нужен для голоса | голосовой ввод в Mini App и голосовые сообщения боту (Whisper; бесплатный ключ на console.groq.com) |
| `QYDYR_CLAUDE_MODEL` | нет | по умолчанию `claude-haiku-5-5` |
| `QYDYR_CLAUDE_MODEL_SMART` | нет | по умолчанию `claude-sonnet-5-5` |
| `QYDYR_PUBLIC_URL` | нет | только для своего домена; иначе берётся домен Railway |
| `QYDYR_BOT_USERNAME` | нет | бот узнаёт своё имя сам при старте |
| `QYDYR_USER_AGENT` | нет | как представляться сайтам афиш |

`PORT` Railway задаёт сам. Режим репетиции (`QYDYR_DEMO_NOW`, `QYDYR_WEATHER_FILE`) на живом демо не включайте: время и погода будут ненастоящими.

## 3. Что происходит при старте

```
init-db  →  seed (в фоне)  →  serve
```

- `init-db` — схема базы, безопасно на каждом старте.
- `seed` заполняет только то, чего в базе нет, и ничего не трогает, если всё есть:
  - мест из OpenStreetMap нет → загрузка из Overpass;
  - данные 2ГИС из `seed/dgis_items.jsonl.gz` (2 344 карточки) ещё не загружены → загрузка и слияние с местами: 3 663 места;
  - событий нет → сбор афиш;
  - нет карты дефицитов или места поменялись → аудит города (~1–2 минуты).
- `serve` стартует сразу, `/health` отвечает, пока `seed` работает.

Проверено на копии базы: первый старт — 2ГИС загружен и аудит готов за ~70 секунд, второй — `seed` ничего не делает.

## 4. Проверка после деплоя

- `https://<домен>/health` → `{"ok":true}`;
- `https://<домен>/app/` — Mini App: спросите «я в Керуене с ребёнком, есть 2 часа», в карточках будут «★ 4,9» и «ТРЦ Керуен, 3 этаж»;
- `https://<домен>/app/city.html` — карта дефицитов;
- в Telegram: `/start` боту, кнопка меню «Карта» открывает Mini App. Команды и кнопку бот ставит сам при старте.

В логах Railway: `seed: 2ГИС 2344 items…`, `audit …`, `seed: done`, `bot @… is polling (Mini App: https://…/app/)`.

## 5. Обновление данных по расписанию

`.github/workflows/collect.yml` в GitHub Actions:
- места — раз в сутки;
- события и аудит — каждые 6 часов;
- 2ГИС — по понедельникам, не больше 200 запросов.

В GitHub → **Settings → Secrets and variables → Actions** добавьте `DATABASE_URL`, `ANTHROPIC_API_KEY` и, по желанию, `QYDYR_DGIS_KEY`. Расписание GitHub запускает только в ветке по умолчанию: смёржите ветку в неё или сделайте её веткой по умолчанию.

## Частые проблемы

- **`Conflict: terminated by other getUpdates request`** — бот с тем же токеном запущен где-то ещё: на ноутбуке, в Render, во второй реплике. Пока работает Railway, не запускайте бота локально с этим токеном. Несколько таких строк сразу после деплоя — норма: старый контейнер ещё досыпает.
- **Нет подключения к базе** — нужна строка Session pooler (порт 5432, хост `*.pooler.supabase.com`), а не Direct connection: прямое подключение у Supabase только по IPv6.
- **Кнопка «Карта» не появилась** — у сервиса нет домена (шаг 1.2) или `QYDYR_PUBLIC_URL` не https.
- **2ГИС отвечает `apiKeyIsBlocked`** — у ключа кончилась квота. Ассистент продолжает работать: адрес просит заменить названием места или геолокацией.
