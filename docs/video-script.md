# Сценарий демо-видео (YouTube, ~3,5 минуты)

Записывайте в демо-режиме, чтобы данные и время совпадали с кадрами:

```bash
python -m qydyr_data demo-data          # или реальные данные: places + events
make demo                               # пятница 19:10, погода из файла
make tunnel                             # https-адрес для Mini App → QYDYR_PUBLIC_URL
```

Телефон в тёмной теме Telegram, уведомления выключены, запись экрана 60 fps.

Для сцены с прогулкой откройте Mini App с параметром `?tour=independence`: карточка маршрута откроется сразу. В демо-режиме время 19:10, поэтому у Национального музея появится подсказка о вечерней выставке.

**Запасной план.** Если интернет на площадке нестабилен, ноутбук с `make demo` работает офлайн: данные, погода и карта (тёмный фон без подложки) не требуют сети.
