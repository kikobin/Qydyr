# Сценарий демо-видео (~3 минуты)

## Перед записью

1. **Render задеплоен** на последний коммит (Manual Deploy → Deploy latest commit), бот запущен **только там**: старый Railway удалён, локально бот не запущен.
2. **Время зафиксировано.** В Render → Environment временно добавьте `QYDYR_DEMO_NOW=2026-10-23T19:10` (пятница, вечер: всё открыто, идут события), сохраните и дождитесь перезапуска. После записи переменную удалите.
3. **Голос:** в Render задан `GROQ_API_KEY`. Проверьте: отправьте боту голосовое «кофе у Хан Шатыра».
4. **Inline:** в @BotFather `/setinline` (и по желанию `/setinlinegeo`).
5. **Сервер прогрет:** за минуту до записи откройте `https://qydyr.onrender.com/health`. Бесплатный план засыпает через 15 минут.
6. **Группа:** чат «Пятница после пар» с ботом и 2 друзьями, которые ответят по сценарию.
7. **Телефон:** «Не беспокоить», 100% заряда, крупный шрифт Telegram не нужен. Перед записью очистите чат с ботом.

## Как записывать

- **Телефон:** встроенная запись экрана (iPhone: Пункт управления → Запись экрана; Android: шторка → «Запись экрана»). Звук не нужен.
- **Ноутбук** (страницы «Для города» и «Пульс»): OBS Studio или QuickTime (Mac: ⌘⇧5). Окно браузера 1440×900, масштаб 100%.
- **Голос за кадром:** отдельно, в тишине, на микрофон наушников, по тексту из таблицы. Так проще перезаписать фразу.
- **Монтаж:** CapCut (бесплатно). Телефонные кадры по центру на светлом фоне `#F3EBDD`, ускорение ожиданий ответа ×2, субтитры автоматом.
- Каждую сцену пишите отдельным коротким клипом: ошибся — переснял только её.

## Запасной план

Если сеть на площадке плохая, запустите локально: `make demo` (пятница 19:10, погода из файла) и `make tunnel` для HTTPS-адреса Mini App. Данные и погода работают без сети; без интернета карта будет на однотонном фоне без подложки.
